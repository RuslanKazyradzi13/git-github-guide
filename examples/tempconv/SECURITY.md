# Политика безопасности

## Поддерживаемые версии

Исправления безопасности выпускаются только для последней версии.

| Версия | Поддерживается |
| --- | --- |
| 1.0.x | Да |
| < 1.0 | Нет |

## Как сообщить об уязвимости

**Не создавайте публичный Issue.** Сообщите закрыто одним из способов:

- через GitHub: раздел безопасности репозитория → **Report a vulnerability** (если включено закрытое сообщение об уязвимостях);
- по почте: [АДРЕС ДЛЯ СООБЩЕНИЙ О БЕЗОПАСНОСТИ].

Укажите:

- версию программы и операционную системы;
- шаги для воспроизведения;
- возможные последствия.

## Что будет дальше

- Подтверждение получения — в течение [СРОК, например 5 рабочих дней].
- Оценка и план исправления — после проверки сообщения.
- Публикация сведений об уязвимости — после выхода исправления, по согласованию с вами.

Пожалуйста, не раскрывайте детали уязвимости публично, пока исправление не выпущено.
