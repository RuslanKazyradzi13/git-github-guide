# 0001. Настройки — через переменные окружения

Статус: принято
Дата: 2026-10-11

## Контекст

Пользователям нужно менять число знаков после запятой. Хотелось бы не добавлять файл настроек и внешние библиотеки.

## Решение

Читать настройку из переменной окружения `TEMPCONV_PRECISION`. Неверное значение заменять значением по умолчанию. В репозитории хранить образец `.env.example`, а не `.env`.

## Последствия

- Программа остаётся без внешних зависимостей.
- Настройку легко задать в скрипте или в CI.
- Пользователь сам задаёт переменные: программа не читает файл `.env` автоматически.
