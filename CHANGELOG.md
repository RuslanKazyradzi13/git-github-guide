# Журнал изменений

Все заметные изменения методички записываются в этот файл.

Формат основан на [Keep a Changelog 1.1.0](https://keepachangelog.com/ru/1.1.0/), версии нумеруются по [Semantic Versioning](https://semver.org/lang/ru/). Что означает каждая часть номера для методички — в [CONTRIBUTING.md](CONTRIBUTING.md#версии).

## [1.0.0] — 2026-10-11

### Добавлено

- Часть I «Git и GitHub с нуля», главы 1–8: установка Git на Windows, основные команды, работа с GitHub, ветки и Pull Request, конфликты и восстановление изменений, Git и AI-ассистент, практика и итоговые проекты.
- Часть II «Как создавать, оформлять и публиковать программные проекты по международным практикам», главы 9–11: стандарты и оформление проектов, лицензии и авторские права, безопасность и автоматизация.
- Словарь терминов и список источников с датой проверки.
- 9 шаблонов документов проекта и 25 схем.
- Учебный проект `examples/tempconv` — пример профессионально оформленного репозитория.
- PDF-версия с оглавлением, номерами страниц и закладками.
- Анимация в README, файлы сообщества (CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, CITATION.cff), формы Issue, шаблон Pull Request и автоматические проверки оглавлений, схем и ссылок.
