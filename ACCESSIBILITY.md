# Доступность

Методичка должна быть доступна каждому, кто учится. В том числе людям, которые читают с помощью программы экранного доступа, работают только с клавиатуры, увеличивают экран или включают высокую контрастность.

## Что уже сделано

- **Главное передаёт текст.** Схемы, диаграммы и анимация иллюстрируют текст главы, а не заменяют его.
- **У всех изображений есть текстовое описание** (атрибут `alt`): у схем, значков и анимации.
- **Цвет — не единственный признак.** Ветки на схемах подписаны (`main`, `feature`), опасные команды отмечены словами и знаком ⚠.
- **Схемы в формате SVG** можно увеличивать без потери чёткости.
- **Понятная структура.** Заголовки идут по порядку уровней, у таблиц есть строка заголовков, у блоков кода указан язык (`powershell`, `text`).
- **Примечания с текстовой меткой.** Блоки NOTE, TIP, IMPORTANT, WARNING и CAUTION различаются не только цветом, но и названием.
- **Анимация в README** не мигает чаще трёх раз в секунду. Всё, что в ней показано, повторено текстом в разделе «Первый коммит за 10 минут». Есть версии для светлой и тёмной темы GitHub.
- **PDF-версия** размечена для программ экранного доступа (tagged PDF): указан язык документа, есть закладки и оглавление со ссылками, текст можно выделять и озвучивать.

## Где читать

| Где | Что учтено |
| --- | --- |
| Сайт GitHub, светлая и тёмная тема | Основной формат: README, главы, схемы, диаграммы Mermaid |
| Редактор кода или программа просмотра Markdown | Главы читаются как обычный текст, картинки лежат в папке `images/` |
| PDF-версия | Размеченная структура, язык документа, закладки |

## Как остановить анимацию на GitHub

GitHub по умолчанию следует системной настройке «уменьшить движение». Чтобы выключить автозапуск GIF вручную: **Settings** → **Accessibility** → раздел **Motion** → **Autoplay animated images** → **Disabled**.

## Известные ограничения

- **Диаграммы Mermaid** GitHub рисует во встроенном окне, и программа экранного доступа может не прочитать их содержимое.
- **SVG-схемы** вставлены как изображения: программа экранного доступа прочитает их описание, но не отдельные подписи внутри схемы.
- **Анимацию нельзя поставить на паузу** внутри README. Её можно только отключить настройкой GitHub (см. выше).
- **Вывод команд Git на английском**, как в настоящей программе. Перевод и пояснения даны в тексте.
- **PDF свёрстан под формат A4** и не подстраивается под ширину экрана. На телефоне удобнее читать на GitHub.
- **Проверку с программами экранного доступа** (NVDA, JAWS, «Экранный диктор» Windows) пока не проводили.

## Как сообщить о барьере

[Создайте Issue по форме «Барьер доступности»](https://github.com/RuslanKazyradzi13/git-github-guide/issues/new?template=5-dostupnost.yml). Напишите, где возникла трудность, чем вы пользуетесь (браузер, программа экранного доступа, увеличение экрана) и что помогло бы.

Сообщения о барьерах рассматриваются наравне с ошибками в тексте. Если вы готовы помочь с исправлением — см. [CONTRIBUTING.md](CONTRIBUTING.md).
