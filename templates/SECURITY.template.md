## Как сообщить об уязвимости

**Не создавайте публичный Issue, Pull Request или обсуждение.** Публичное описание до выхода исправления помогает злоумышленникам атаковать пользователей.

Сообщите закрыто:

<!-- Оставьте только реально работающие каналы. -->
- через GitHub: раздел безопасности репозитория → **Report a vulnerability**;
- по почте: [АДРЕС ДЛЯ СООБЩЕНИЙ О БЕЗОПАСНОСТИ].

Пожалуйста, укажите:

- версию программы и окружение (ОС, версия языка);
- описание уязвимости и её возможные последствия;
- шаги для воспроизведения или пример;
- известные вам способы обойти проблему.
